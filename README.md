# Corpus Nexus

Corpus Nexus now includes an enterprise-grade CorpusGuard AI assistant for the Swecha ecosystem.

## Highlights
- Unified enterprise assistant for project, repository, documentation, API, database, Docker, deployment, architecture, coding, and general programming questions.
- Hybrid retrieval with BM25-style relevance, metadata filtering, and query rewriting.
- Ollama-backed LLM architecture with model routing for deployment, code, and architecture-oriented queries.
- Premium assistant UI with streaming, markdown, code copy, conversation history, regenerate, rename, export, and delete actions.
